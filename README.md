# 茶时 · Ночная чайная

**Красивый таймер проливов для гунфу ча.**
Фонарь наполняется светом, в окнах деревни горит огонь, по небу иногда пролетает дракон.

## Как пользоваться

1. Открой приложение, выбери **с промывкой** или **без** и нажми **«Зажечь фонарь»**.
2. Залей воду на лист и нажми **«Старт»** (или просто коснись фонаря).
3. Фонарь наполнится светом, по сигналу сливай настой. Следующий пролив уже подготовлен.

Проливы добавляются сами, без ограничений: **15 · 15 · 20 · 25 · 30 · 40 · 50 · 60 с**, дальше каждый следующий длиннее (+10 с, можно поменять в настройках).
Горчит — жми **−5 с**, слабо — **+5 с**.

## Что внутри

- 🏮 Универсальный режим проливов, промывка по желанию, автозапуск следующего пролива
- 📜 Мини-гайд по заварке: прогрев посуды, засыпка листа, аромат, промывка, проливы, шпаргалка по температурам
- 🎨 Выбор главного цвета, времени суток (ночь, закат, предрассвет) и погоды (снег, лепестки, дождь, ясно)
- 🐉 Дракон, небесные фонарики, фейерверк на каждый 5-й пролив, кот на крыше, лодка на реке
- 🔔 Колокол, гонг или муюй и фоновая музыка гучжэна, всё синтезируется прямо в приложении
- ⌨️ Пробел — старт/пауза, ← → — ∓5 с, N — следующий, G — гайд, D — дракон
- 📴 Работает без интернета и ничего никуда не отправляет

## Установка

Скачай **`Chashi-Setup-x.y.z.exe`** со [страницы релизов](https://github.com/Ernomoon/Chashi/releases/latest) и пройди установщик: выбор папки, ярлык на рабочем столе и в меню «Пуск».
Если не хочешь устанавливать, есть **`Chashi-Portable-x.y.z.exe`**, он запускается сразу.

> Windows может показать окно SmartScreen, потому что у приложения нет платной цифровой подписи.
> Нажми **«Подробнее» → «Выполнить в любом случае»**.

## Для разработчиков

```bash
npm install
npm start      # запустить
npm run dist   # собрать установщик (на Windows)
```

Сайт целиком лежит в `app/index.html`, оболочка на Electron в `main.js`.
Установщик собирается автоматически в GitHub Actions при пуше тега `v*`.
